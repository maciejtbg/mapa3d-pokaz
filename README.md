# Mapa3D Grabber: pokaz

Strona z krótkimi filmami pokazowymi programu Mapa3D Grabber: teren 3D z Gdyni w kanale dziennym i w widoku z kamery termowizyjnej głowicy obserwacyjnej.

Strona: https://maciejtbg.github.io/mapa3d-pokaz/

Filmy (do 30 s każdy) są oznaczone „For promotional purposes only”. Dane 3D terenu: Google (Google Maps). Repozytorium zawiera tylko stronę i filmy, bez kodu programu i bez danych terenu.
